# 🚀 Full JS Quiz SPA – OOP, CRUD & Nutrition Tracker

## 📌 Overview

This project represents my **first comprehensive JavaScript SPA** (Single Page Application).

It is a dynamic quiz and nutrition tracker built using **vanilla JavaScript** with full **OOP principles**, **CRUD operations**, **filtering**, and **real-time calculations**.

Users can:

- Answer quizzes covering all JS concepts  
- Add, edit, and delete food items (CRUD)  
- Filter items by category  
- Calculate **protein intake** and **weekly calories**  
- Navigate between SPA routes without page reload
